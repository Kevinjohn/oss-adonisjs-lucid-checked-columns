# Decision gaps

One was identified between the [README](../README.md), the [changelog](../CHANGELOG.md) and the [source](../src/) during this catalogue pass: the 0.3.0 changelog entry omits the `/types` entry that release added. The [Unreleased](../CHANGELOG.md#unreleased) section records the correction; the published entry is not rewritten. No separate product decision record is present. The following boundaries are retained intentionally, not unresolved feature requests.

| Boundary             | Contract and source                                                                                                                                                                                           | Catalogue treatment                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Model path only      | Lucid runs `prepare` and `consume` for model reads and writes only; query-builder writes bypass them ([README](../README.md#limits)).                                                                         | US-COLUMN-01/02 cover model saves and hydration; US-COLUMN-03 helps host code that writes outside the model but does not validate for it. |
| Reject, never repair | The helpers refuse rather than repair a value ([README](../README.md#limits), [ISO columns](../src/iso_column.ts)).                                                                                           | US-COLUMN-02 requires the driver and column type to return the canonical string; a driver that returns a `Date` is refused on read.       |
| Driver behaviour     | Unit model tests use an in-memory adapter ([tests](../tests/json_column.spec.ts)); the [packed consumer fixture](../examples/release-consumer/model.ts) additionally runs saves and hydration against SQLite. | Stories describe the column hooks, with real SQLite text storage verified; other drivers' encodings are not claimed.                      |
